# HomeFull

Персональний Telegram-помічник для пошуку квартири у Львові. Збирає OLX, DOM.RIA,
Rieltor і ЛУН/Flatfy, перевіряє вимоги кожного користувача та надсилає фото,
основні характеристики, публічний контакт і пряме посилання на оголошення.

## Запуск

Потрібен Python 3.12 або новіший.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e .
python -m playwright install chromium
Copy-Item .env.example .env
# Заповни TELEGRAM_BOT_TOKEN у .env
homefull
```

Перевірка налаштувань без запуску бота: `homefull --check-config`.

HomeFull читає лише власний `.env` та змінні середовища. Він не залежить від інших
папок чи навчальних проєктів. База, критерії, черга повідомлень та історія пошуку
зберігаються локально в `data/`; ці файли та `.env` не потрапляють у Git.

## Керування кнопками

Після привітання Telegram показує постійне меню:

| Кнопка | Дія |
|---|---|
| 🔎 Знайти квартири | Перевіряє наступні відповідні оголошення з бази |
| 📊 Статус пошуку | Показує поточний етап, кількість карток і результати відбору |
| ⏸ Пауза | Зупиняє нові етапи особистого пошуку та сповіщення |
| ▶️ Відновити | Відновлює особистий пошук |
| ⚙️ Мої вимоги | Показує збережені критерії |

Вимоги задаються звичайним повідомленням і підтверджуються кнопкою «Зберегти».
Запитання на кшталт «Знайшов щось?» запускають підбір і не перезаписують критерії.
Кожен користувач має власні вимоги. Якщо всі користувачі призупинили пошук,
планувальник не завантажує каталоги. Уже розпочатий запит може завершитися після
натискання паузи, але наступні етапи та надсилання зупиняються.

## Прогрес і статистика

Повідомлення пошуку оновлюється під час роботи: збір джерел → характеристики →
перевірка описів → надсилання. Окремо видно поточну кількість перевірених описів.
Кнопка статусу доступна під час довгої перевірки; повторне натискання пошуку
не створює другу особисту перевірку.

Статус містить загальну кількість оголошень, дублікати, доступні та зняті картки,
кількість кандидатів після первинних фільтрів, перевірені й неперевірені описи,
попередні збіги, надіслані повідомлення та основні причини відсіву. Історія етапів
зберігається у SQLite; перерваний перезапуском пошук позначається як перерваний.
Відсутність картки в одній сторінці каталогу не вважається доказом її зняття:
недоступність підтверджується відповіддю 404/410.

## Вік оголошення та посилання

- На OLX читається оригінальний `createdTime`, окремо від `lastRefreshTime` та підняття.
- Дата оригінального джерела показується, коли воно її публікує.
- Для ЛУН дата додавання до агрегатора позначається саме як «У ЛУН»; вона не
  видається за дату створення оригінального оголошення.
- Коли доступна сторінка оригіналу з OLX, Rieltor або DOM.RIA, HomeFull доповнює
  картку її характеристиками та датою публікації.
- Якщо дата невідома, повідомлення окремо вказує час спостереження ботом.
- Для дат без точного часу не показуються вигадані години.
- ЛУН читається з публічного стану сторінки: використовується `url_raw`
  оригінального оголошення або конкретна картка `lun.ua/uk/realty/<id>`.
  Загальні пошукові посилання не надсилаються. Старі картки без прямого посилання
  чекають доповнення та видимі окремим лічильником у статусі.

## Налаштування

| Змінна | Типове значення | Призначення |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | обов'язкова | Токен Telegram-бота |
| `POLL_MINUTES` | `10` | Інтервал автоматичного збору |
| `PAGES` | `3` у прикладі | Кількість сторінок кожного джерела |
| `HOMEFULL_DATA` | `data/` | Каталог особистих даних |
| `HOMEFULL_TIMEZONE` | `Europe/Kyiv` | Часовий пояс відображення дат |
| `LLM_PROVIDER` | `auto` | `auto`, `cli`, `codex`/`gpt`, `api` або `fake` |
| `LLM_MODEL` | модель провайдера | Модель Claude |
| `CODEX_MODEL` | стандартна модель Codex | Необов'язковий вибір моделі GPT |
| `ANTHROPIC_API_KEY` | порожнє | Потрібна лише для `LLM_PROVIDER=api` |

Локально `auto` використовує підписку Claude через `claude -p`, а за її
недоступності — підписку ChatGPT через офіційний Codex CLI. Перед запуском
увійди в потрібні CLI. Codex-запити ізольовані в тимчасовій папці та виконуються
без інструментів і плагінів. Авторизаційні файли нікуди не копіюються.

Якщо обидва провайдери недоступні, використовується позначений резервний відбір
за явними словами. Непідтверджена газова плита та непідтверджений дозвіл на тварину
не проходять відповідні обов'язкові вимоги в цьому режимі. Після відновлення
провайдера резервні результати перевіряються знову.

## Автоматичний запуск Windows

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install_task.ps1 -PythonExe (Get-Command python).Source
```

Завдання `HomeFull` стежить за процесом кожні 5 хвилин і після входу користувача.
Його встановлення — окрема дія; сам запуск програми не створює системних завдань.
Вимкнення: `Disable-ScheduledTask -TaskName HomeFull`.

## Docker

```bash
docker compose up --build -d
```

У контейнері типовий режим — `fake` (простий відбір без підписок). Для повного
аналізу через Anthropic задай `HOMEFULL_CONTAINER_LLM_PROVIDER=api` та
`ANTHROPIC_API_KEY` у `.env`. Локальні підписки CLI не переносяться в контейнер.
Модель оцінки ціни необов'язкова: локальний `data/fair_price.pkl` використовується,
якщо присутній; без нього пошук і сповіщення працюють без прогнозу ціни.

## Розробка

```bash
pip install -e ".[dev]"
python -m pytest -q
```

Збір без Telegram-повідомлень: `python scripts/collect.py --pages 3`.
Джерела читаються з паузами та перевіркою `robots.txt`; 403/429 зупиняють джерело.
Контакти беруться з публічного опису або звичайної кнопки показу телефону.
